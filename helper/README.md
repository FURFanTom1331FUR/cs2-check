# Помощник CS2 Check (`helper/`)

Маленький локальный сервер на Node.js. Он нужен, чтобы сайт мог **сам скачать демку** найденного матча:
ссылку на демку (`http://replayNNN.valve.net/730/…dem.bz2`) выдаёт только игровой координатор CS2 авторизованному
клиенту Steam, а сервера повторов Valve отдают файлы только по HTTP и без CORS.

Помощник:

- слушает **только** `127.0.0.1:27901` (с других компьютеров недоступен);
- отвечает только сайту `https://cs2-check.pages.dev` (и локальной разработке `127.0.0.1:8788`); запросы с других сайтов и с чужим `Host` отклоняются;
- качает только `http://replay*.valve.net/730/*.dem.bz2` (до 700 МБ) и отдаёт поток браузеру — распаковка и разбор идут на сайте;
- ничего не хранит, кроме refresh-токена бота в режиме `bot` (`helper/.bot-data/`, в git не попадает).

| Адрес | Что делает |
|---|---|
| `GET /health` | статус и режим |
| `POST /match {"shareCode":"CSGO-…"}` | ссылка на демку, время, счёт матча |
| `POST /recent` | последние 8 матчей вашего аккаунта (только режим `boiler`) |
| `GET /demo?url=…` | поток `.dem.bz2` с сервера повторов |

## Установка

1. Установите [Node.js](https://nodejs.org/ru) 20+ (LTS).
2. Скачайте репозиторий и откройте папку `helper` в терминале (PowerShell).
3. `npm install`
4. `npm start` — появится «помощник слушает http://127.0.0.1:27901». Окно не закрывайте.
5. На сайте откройте «Мои матчи» → «Проверить помощника». Chrome может спросить разрешение на доступ к локальной сети — разрешите.

## Режим `boiler` (по умолчанию, без паролей)

Использует [boiler-writter](https://github.com/akiver/boiler-writter) (тот же, что в CS Demo Manager): через Steamworks API
**вашего уже запущенного клиента Steam** он спрашивает у координатора CS2 информацию о матче. Логин и пароль не нужны
и помощнику не передаются.

- Steam должен быть запущен, вы — вошли в аккаунт; **CS2 должна быть закрыта** (на время запроса в фоне кратко поднимается CS2-клиент Steamworks, до ~1 минуты).
- Запрос идёт от имени вашего аккаунта так же, как если бы вы открыли «Смотреть → Ваши матчи» в игре.
- Работает на Windows x64, macOS, Linux x64.

## Режим `bot` (отдельный аккаунт)

Для сервера, который работает без вашего ПК, или если не хочется трогать свой Steam. Скопируйте `.env.example` в `.env`:

```
HELPER_BACKEND=bot
BOT_STEAM_LOGIN=логин_бота
BOT_STEAM_PASSWORD=пароль_бота
BOT_STEAM_SHARED_SECRET=shared_secret_из_мобильного_аутентификатора
```

Требования к бот-аккаунту:

- **отдельный** аккаунт Steam, **не ваш основной** (им нельзя одновременно играть: координатор держит одну сессию);
- CS2 добавлена в библиотеку (бесплатно: «Играть» в магазине или `requestFreeLicense`);
- Steam Guard: лучше мобильный аутентификатор и его `shared_secret` (steamguard-cli / SDA) — тогда вход без участия человека;
  без него помощник попросит код из письма/приложения в консоли при первом входе;
- после первого входа сохраняется refresh-токен (`.bot-data/refresh-token.txt`, права 600), пароль из `.env` можно убрать;
- «ограниченный» аккаунт (без покупок на $5) обычно может подключаться к координатору CS2, но Valve это не гарантирует.

Помощник спрашивает координатор не чаще раза в 3 секунды и ждёт ответ 20 секунд.

## Где запускать

| Где | Плюсы | Минусы |
|---|---|---|
| **ваш ПК** (рекомендуется, режим `boiler`) | без аккаунтов и паролей; демка идёт ПК → браузер | ПК и Steam должны быть включены; CS2 закрыта во время запроса |
| сервер/VPS (режим `bot`) | работает всегда, можно открыть другим | нужен бот-аккаунт, публичный HTTPS-адрес (сейчас сайт ищет помощника только на 127.0.0.1), трафик демок |
| бесплатный хостинг | — | Render/Railway засыпают и рвут Steam-соединение; Oracle Always Free требует карту. Cloudflare Workers не подходят: нет постоянного TCP-соединения со Steam |

## Риски

- **Правила Valve.** Соглашение подписчика Steam запрещает автоматизацию/ботов в играх. Запросы информации о матчах ботами
  делают многие сервисы (Leetify, CS Demo Manager, csstats), но формально бот-аккаунт может быть ограничен. Не используйте основной аккаунт.
- **Лимиты координатора.** При частых запросах координатор молча перестаёт отвечать (таймаут 20 с). Не больше одного запроса за несколько секунд.
- **Безопасность.** `.env` и `.bot-data/` не коммитьте; пароль бота не должен совпадать с вашими. Код аутентификации игры даёт доступ только к истории матчей.
- **Срок жизни демок.** Valve удаляет записи примерно через месяц — старые матчи скачать нельзя.

## Тесты

```
npm test
```

Проверяются: извлечение ссылки на демку из ответа координатора, CORS/Private Network Access, отказ чужим сайтам и `Host`,
белый список адресов Valve, коды выхода boiler-writter (и настоящий бинарник без Steam), бот без учётных данных — без попытки входа.
