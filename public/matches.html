Мои матчи CS2

Введите профиль, код аутентификации и код последнего матча — сайт сам найдёт ваши новые официальные матчи (Premier, соревновательный, напарники). Демку можно разобрать здесь же, а ручная загрузка файла по-прежнему работает на странице «Разбор демки».

🔒 Коды хранятся только в этом браузере (localStorage). Код аутентификации уходит лишь на наш сервер для одного запроса к Steam и нигде не сохраняется и не записывается в логи. Он даёт доступ только к истории матчей, а не к аккаунту. Отозвать его можно на той же странице Steam.

Где взять коды?
  1. Откройте страницу Steam «Доступ к истории матчей CS2» (нужно войти в Steam).
  2. Нажмите «Создать код аутентификации» — появится код вида AAAA-AAAAA-AAAA. Это и есть код аутентификации игры.
  3. Ниже на той же странице есть код последнего матча CSGO-…. Ещё его можно взять в CS2: «Смотреть» → «Ваши матчи» → выбрать матч → «Поделиться» (копировать код).
  4. Вставьте оба кода сюда. После первого поиска сайт запомнит самый новый код, и в следующий раз нужно будет просто нажать «Найти матчи».

Код матча — это не демка, а «адрес» матча у Valve. Сами записи (демки) хранятся на серверах Valve около месяца.

Демки матчей

Код матча сам по себе не содержит ссылки на демку — её выдаёт только игровой координатор CS2 авторизованному клиенту Steam. Поэтому для автоматической загрузки нужен небольшой помощник на вашем ПК (открытый код, папка helper/ в репозитории). Без него демку можно скачать в CS2 («Смотреть» → «Ваши матчи» → загрузить) и выбрать файл на странице «Разбор демки» — теперь подходят и .dem, и .dem.bz2.

Помощник не проверялся.
Как запустить помощника
  1. Установите Node.js 20 или новее.
  2. Скачайте репозиторий (GitHub → Code → Download ZIP) и распакуйте.
  3. В папке helper выполните npm install, затем npm start.
  4. Держите Steam запущенным (вход в свой аккаунт), а CS2 — закрытой. Нажмите «Проверить помощника».

Помощник слушает только 127.0.0.1:27901 и отвечает только этому сайту. Подробности и режим с отдельным бот-аккаунтом — в README.

Список матчей берётся из официального Steam Web API (GetNextMatchSharingCode). Сайт не связан с Valve.
